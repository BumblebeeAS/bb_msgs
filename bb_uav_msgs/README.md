# BB UAV Messages

This package contains the messages used by the BB UAV/Jellyfish2 system. Work In Progress

## Messages

The following messages are defined in this package:

- `Jellyfish2Pose`: A message used to provide target lat-long and heading. 
- `JellyfishHeartbeat`: Heartbeat boolean(used in RobotX 2022)
