# BB Behavior Messages

This package contains the messages used by the BB Behavior system.

## Messages

The following messages are defined in this package:

- `BehaviorFeedbackMsg`: A message used to provide feedback to the user about the status of the behavior tree execution.

## Actions

The following action is defined in this package:

- `Mission`: An action used to execute a mission.
